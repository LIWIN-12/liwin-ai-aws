# Project 1

## Project Name

Smart Focus – AI Powered Student Engagement Tracking System

## Category

Computer Vision
Artificial Intelligence
Deep Learning

## Status

Completed

## Overview

Smart Focus is an AI-powered classroom monitoring system that automatically tracks student engagement using Computer Vision techniques.

The system detects student activities such as attentiveness, mobile phone usage, sleeping, reading, and other classroom behaviors while simultaneously recording attendance using face recognition.

The goal of the project is to help educators better understand classroom engagement without manually monitoring every student.

---

## Problem Statement

Traditional classroom monitoring requires continuous observation by teachers, making it difficult to accurately track student engagement and attendance.

---

## Solution

Developed an intelligent monitoring system capable of:

- Detecting students
- Recognizing faces
- Marking attendance
- Detecting classroom behaviors
- Measuring engagement
- Generating reports

---
